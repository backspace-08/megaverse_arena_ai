ЧТО Я МОГУ ВЫВЕСТИ (INFERENCE)
======================================================================
После каждого opponent хода я наблюдаю:
  - total_attacks
  - spent_shields
  - switch (yes/no)
  
Из этого вывожу:
  
  remainder = actions - attacks - switch_cost
  
  Этот remainder был распределён между:
    - shields (которые я только что увидел spent)
    - bonus (который пошёл в bank)
  
  bonus_banked = remainder - spent_shields
ПРИМЕР:
Turn 3, AI ход:

  AI spent shields: 1 (который я поставил на Turn 2)
  AI switch: no

  НО ПОДОЖДИ! Shields которые я вижу spent — это МОИ shields!

ПРАВИЛЬНАЯ ИНФОРМАЦИОННАЯ МОДЕЛЬ
======================================================================
На Turn N (мой ход), после opponent хода N-1:
ИЗВЕСТНО:
  1. Opponent available actions на ЕГО ход N-1: budget_N-1
  2. Opponent attacks на ходу N-1: attacks_N-1
  3. Opponent spent MY shields: my_shields (это МОИ shields!)
  4. Opponent switch: switch_N-1
  
ВЫВОЖУ:
  remainder_N-1 = budget_N-1 - attacks_N-1 - switch_N-1
  
  Этот remainder был распределён на:
    - opponent shields для хода N (СКРЫТО от меня)
    - opponent bonus в bank (СКРЫТО от меня)
  
  opp_shields_N + opp_bonus_banked_N-1 = remainder_N-1
НО Я НЕ ЗНАЮ как именно распределено!
ОДНАКО на следующем ходу (Turn N+1):
  Opponent budget = base_N + bonus_revealed
  
  bonus_revealed = то что было banked на N-1
  
  Значит:
    bonus_revealed = remainder_N-1 - opp_shields_N
    
  Когда я увижу spent opp_shields_N (после resolution Turn N),
  я узнаю: bonus_revealed = remainder_N-1 - opp_shields_N

BELIEF TRACKING
======================================================================
На момент МОЕГО хода Turn N:
Opponent на своём прошлом ходу (N-1) имел:
  actions = A
  attacks = X
  remainder = R = A - X - switch
  
Opponent распределил R между:
  shields_for_N (защита от МОЕЙ атаки)
  bonus_banked (для хода N+1)
Я НЕ ЗНАЮ это распределение до resolution!
BELIEF DISTRIBUTION:
  P(shields=0, bonus=R) = ?
  P(shields=1, bonus=R-1) = ?
  ...
  P(shields=R, bonus=0) = ?
Это зависит от opponent стратегии!
Если opponent aggressive:
  -> Больше probability на bonus
  
Если opponent defensive:
  -> Больше probability на shields

def query_nash_allocation(state, belief):
    """
    state: текущая позиция
    belief: belief distribution по opponent shields/bonus
    """
    
    # 1. Мои параметры (известны точно)
    my_actions = state.my_actions
    my_shields = state.my_shields
    atd = attacks_to_kill(state.opp_char, state.my_char, my_shields)
    
    # 2. Opponent параметры (belief)
    expected_atk = 0.0
    for opp_shields, prob in belief.shields.items():
        atk = attacks_to_kill(state.my_char, state.opp_char, opp_shields)
        expected_atk += atk * prob
    expected_atk = round(expected_atk)
    
    # 3. Opponent future actions (belief)
    base_next = base_actions(state.turn + 2)  # его следующий ход
    expected_bonus = sum(b * p for b, p in belief.bonus.items())
    expected_opp_actions = base_next + round(expected_bonus)
    expected_opp_actions = min(8, expected_opp_actions)
    
    # 4. Query
    key = (expected_atk, atd, my_actions, expected_opp_actions)
    
    if key in nash_table:
        return nash_table[key]
    else:
        # Fallback
        return heuristic_allocation(expected_atk, atd, my_actions)
